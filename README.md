# Crassostrea gigas population genomics

This is the GitHub archive of materials for Sotka et al. The genetic legacy of a global marine invader.

## ABC_input. 

This folder contains the genetic and metadata for each of the 14 co-invaded species used in the ABC analysis. It also contains a comparison of the mean posterior probabilities from the two oyster models (Machine learning vs PC) in the compare_Admix_ML folder.

### Final figures

FINALFIGS folder contains materials that help to create each of the figures in the manuscript. 

### Shipping analysis

This folder contains the 30-day matrix of shipping vectors taken from the ICOADS dataset. It also includes .kml files of the regions we used to track ships.
